## Verdigris (teal dye)

Copper carbonate green pigment from vinegar + raw copper. Colored textile and building products use the **teal** item id prefix (`teal_cotton`, `teal_wool`, etc.) while the dye item remains `materia:verdigris`.

## Recipe

Custom crafting (`materia:verdigris`):

- `#materia:vinegar` + `#forge:raw_materials/copper` (or `minecraft:raw_copper`) → `materia:verdigris`
- Returns the empty vessel: clay bowl for `materia:vinegar`, glass bottle for `materia:vinegar_bottle`, pot/bucket when those forms are used (`materia:vinegar_bucket` → `minecraft:bucket`, `materia:copper_bucket_vinegar` → `materia:copper_bucket`)

## Teal products

Same pattern as olive/burgundy: cotton, wool clump, wool block, string, stained glass, concrete powder, terracotta, candle, carpet, blanket, sack, bed.
