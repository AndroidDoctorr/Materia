## Plants and farming tags

These tags show up in farming, vines, and plant-based crafting.

Source of truth:

- item tags: `shared/src/main/resources/data/materia/tags/items/`
- block tags: `shared/src/main/resources/data/materia/tags/blocks/`

## `#materia:seeds`

Used by: crop systems and recipes that accept “any seed”.

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/seeds.json`
- **Includes**: vanilla wheat/beetroot seeds and several modded seeds/crops.

## `#materia:reeds`

Used by: recipes that accept reed-like plants (for fiber/structure).

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/reeds.json`
- **Includes**: sugar cane, bamboo

## `#materia:grape_vine_supports`

Used by: grape vine growth/spreading onto supports.

- This is a **block tag** (not an item tag).
- **Tag JSON**: `shared/src/main/resources/data/materia/tags/blocks/grape_vine_supports.json`
- **Includes**: trellises, posts, joists (various wood types)

See also:

- [Vines (mechanic)](../../mechanics/vines.md)
