## Combat and explosives tags

These tags are used by the cannon/explosives systems to define “valid ammo” categories.

## `#materia:cannon_ammo`

Used by: the cannon loading/ammo rules.

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/cannon_ammo.json`
- **Includes**:
  - `minecraft:tnt`
  - `materia:stone_cannonball`
  - `materia:iron_cannonball`
  - `materia:canister_shot`

See also:

- [Cannons (mechanic)](../../mechanics/cannons.md)

## `#materia:shrapnel`

Used by: shrapnel-style ammo (ex: canister shot internals).

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/shrapnel.json`
- **Includes**: flint/pebble/raw iron plus a few fastener/nugget tags (see the JSON for full list).

See also:

- [Canister shot](../../content/items/canister-shot.md)
