## Dye tags

These tags group dyes by “color family” for recipes that accept “any red dye”, “any blue dye”, etc.

Source of truth: `shared/src/main/resources/data/materia/tags/items/`

## `#materia:red_dyes`

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/red_dyes.json`
- **Includes**: `minecraft:red_dye`, `materia:red_ochre`, `materia:burgundy_dye`

## `#materia:yellow_dyes`

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/yellow_dyes.json`
- **Includes**: `minecraft:yellow_dye`, `materia:ochre`, `materia:tan_dye`

## `#materia:brown_dyes`

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/brown_dyes.json`
- **Includes**: `minecraft:brown_dye`, `materia:tan_dye`

## `#materia:green_dyes`

- **Tag JSON**: `shared/src/main/resources/data/materia/tags/items/green_dyes.json`
- **Includes**: `minecraft:green_dye`, `minecraft:lime_dye`, `materia:olive_dye`, `materia:verdigris` (teal colored products use `teal_*` ids)

## `#forge:dyes/teal`

- **Tag JSON**: `shared/src/main/resources/data/forge/tags/items/dyes/teal.json`
- **Includes**: `materia:verdigris` (alias for recipe mods; player-facing name is teal)
